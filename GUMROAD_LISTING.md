## Long description (Gumroad page)
**MVP — Melodic Vibration Processor**

A modern wavetable synth built for FL Studio on Mac.

**What you get**
- VST3 + AU, 64-bit, macOS (Intel + Apple Silicon)
- 2 wavetable oscillators (morph + warp: Bend / Sync / PWM / Asym / Fold) + Sub + Noise
- Filters, 2x ADSR, 2x LFO, 2 Macros, FX rack (Distortion, Bitcrush, Chorus, Delay, Reverb)
- **Frequency tuning:** 432 / 440 / 444 / 528 Hz + custom — built into every preset
- **2,000 original presets** in ONE bank called Presets, organized by type:
  Bass 300, Synth 260, Pluck 230, Pad 320, Keys 320, Cinematic 300, Arp 200, FX 70
- **Presets folder:** drag & drop .json / .fxp / .fxb files or folders into `~/Documents/MVP/Presets/` — or straight onto MVP. Save your own presets and make your own banks.
- **Themes:** Theme button cycles Manual / Audio Reactive / Time of Day / Weather / Timer. Colors change gradually — day to night, weather, sound — never a sudden flash.

**Install (FL Studio) — no setup, no copying files**
1. Download `MVP-Installer.pkg` from Gumroad
2. Double-click it → Continue → Install
3. Open FL Studio > Manage plugins > Find plugins > MVP pops up

**Originality**
All presets are original parameter sets. No Serum / Omnisphere presets, no artist audio, melodies, or lyrics copied.
